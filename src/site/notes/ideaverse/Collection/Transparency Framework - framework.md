# Transparency Framework

*Transparency label: AI-assisted*

The Transparency Framework explains how we disclose the level of AI involvement in what we publish. It defines a set of standard labels, from Human-only to AI-only, describes each one, and says when and how to apply them, with optional justifications and chat summaries. Its purpose is to make AI's role in a piece explicit and easy for readers to understand.

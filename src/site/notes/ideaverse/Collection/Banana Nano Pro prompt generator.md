# Banana Nano Pro prompt generator

*Transparency label: AI-assisted*

The Banana Nano Pro prompt generator is a workflow built on a custom Gem that produces professional image prompts for Nano Banana Pro. The user acts as creative director and provides context; the Gem acts as technical prompter, turning that input into structured JSON for consistent, high-quality images.

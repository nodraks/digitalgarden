# Anapoly three-layer instruction set

*Transparency label: AI-assisted*

The three-layer instruction set is the text Anapoly AI Labs puts into the custom instructions of a ChatGPT Project. The top layer states the business context: what Anapoly is, whom it serves, its values, boundaries, tone and risk posture. The middle layer governs the model's behaviour, strict by default, with a one-turn override invoked by the keyword OVERRIDE. The bottom layer says how to read the immediate task prompt against the two above it. The lab note [[ideaverse/Collection/Building a three-layer instruction set for Anapoly's work in ChatGPT Projects\|Building a three-layer instruction set for Anapoly's work in ChatGPT Projects]] records how it was built.
